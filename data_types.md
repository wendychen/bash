# Data Types

## declare

`-i` integer, `declare -i num=5+3`
`-r` readonly, `declare -r PI=3.14159` 
`-a` indexed array, `declare -a arr`
`-A` associative array, `declare -A map`
`-x` export, `declare -x PATH=...`
`-l` 小寫, `declare -l name="Hello"`
`-u` 大寫, `declare -u name="Hello"`
`-f` function, `declare -f`
`-p` property, `declare -p var`
